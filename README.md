# Постобработка OCR паспортов РФ

Решение тестового задания по проверке и постобработке результатов распознавания паспортов РФ.

## Запуск

Требуется Python 3.12. Используется только стандартная библиотека, подключение к интернету не требуется.

```bash
python postprocess.py data/test_predictions.jsonl answers.jsonl
```

Входной файл передаётся первым аргументом, выходной - вторым.

## Файлы

- `postprocess.py` — точка входа и принятие решения по документу.
- `ocr_core.py` — проверка OCR, MRZ и действительности паспорта.
- `answers.jsonl` — результаты для 2000 тестовых документов.
- `FINAL_REPORT.pdf` — двухстраничный отчёт с методикой, результатами и ограничениями.

## Результаты

На тестовом наборе принято 357 документов, отклонено 1643. Разметка тестового набора недоступна, поэтому фактическая доля ошибок неизвестна.

Входные данные не включены в репозиторий.
